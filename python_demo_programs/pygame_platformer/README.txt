
Pygame Platformer
=================

Requirements:
    pip install pygame

Run:
    python game.py

Controls:
    A / D or Left / Right arrows: move
    Space / W / Up arrow: jump
    R: restart

Features:
    - Image-based player
    - Image-based platforms
    - Background image
    - Coins
    - Gravity and jumping
    - Platform collision
    - Goal flag
    - Win / game-over screen
